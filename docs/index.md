- 게임 점수 및 기록
- 플레이 시간
- 게임 세션 정보

- 기기 모델 및 운영체제

## 2. 정보 사용 목적

수집한 정보는 다음 목적으로 사용됩니다:

- 게임 진행 상황 저장 및 복원
- 글로벌 리더보드 표시 및 순위 경쟁
- 게임 개선 및 버그 수정
- 서비스 안정성 및 성능 최적화
- 사용자 경험 개선

## 3. 제3자 서비스

QUARK는 다음 제3자 서비스를 사용합니다:

### Google Firebase
- **용도:** 데이터 저장, 사용자 인증, 분석
- **수집 정보:** 게임 플레이 데이터, 익명 사용자 ID, 닉네임
- **개인정보처리방침:** https://firebase.google.com/support/privacy

### Google Play Services
- **용도:** Google 계정 로그인 (선택적)
- **수집 정보:** 이메일 주소, 프로필 정보 (사용자가 동의한 경우에만)
- **개인정보처리방침:** https://policies.google.com/privacy

## 4. 데이터 보안

- Firebase Security Rules를 통한 데이터 접근 제어
- HTTPS 암호화 연결을 통한 안전한 데이터 전송
- 익명 인증을 통한 사용자 식별
- 데이터는 암호화되어 저장됩니다
- 정기적인 보안 업데이트 및 점검

## 5. 데이터 보관 및 삭제

- 게임 플레이 데이터는 게임 서비스 제공 기간 동안 보관됩니다
- 사용자는 언제든지 계정 삭제를 요청할 수 있으며, 계정 삭제 시 관련 데이터는 삭제됩니다
- 계정 삭제 요청은 앱 내 계정 설정에서 직접 삭제하거나 아래 문의처로 연락주시면 처리해드립니다
- 법령에 따라 보관이 필요한 경우 해당 기간 동안 보관됩니다
